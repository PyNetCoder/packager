# Strict Rules for All AI Agents

You MUST strictly adhere to the following rules when modifying or generating code in this repository:

1. **No Code Bloat:** Keep implementations concise, modular, and minimal. Do NOT add unnecessary abstractions, redundant helper functions, or over-engineered logic.
2. **Preserve Code Architecture:** Strictly respect the existing project structure, design patterns, and module boundaries. Do NOT alter the architecture unless explicitly instructed.
3. **English-Only Codebase:** All code elements—including variable names, function signatures, types, docstrings, inline comments, and error messages—MUST remain strictly in English. Do NOT translate code or comments into any other language.
4. **Validation Command:** For formatting and linting, execute ONLY `cargo fmt && cargo clippy -- -D warnings`. Do NOT run `cargo check` separately, and ensure zero warnings remain before completing a task.
5. **Strict Scope Adherence:** Execute ONLY what is explicitly requested. Do NOT refactor unrelated files, modify untouched logic, or introduce unrequested features.
